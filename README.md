# OHAKO-18番-

iPhoneで使う、個人用カラオケレパートリーノートです。

公開先：<https://sethsoui.github.io/OHAKO/>

## 使い始める

1. iPhoneのSafariで公開先を開きます。
2. 共有メニューから「ホーム画面に追加」します。
3. 「追加する」から曲名を登録します。曲名以外は任意です。
4. 設定の「オフラインで使う準備」が完了してから、機内モードでも試してください。

## 機能

- 曲の追加・編集・詳細表示。入力途中は曲ごとに下書き保存。
- 1行約49pxのコンパクトな一覧。分類は色とアイコン、タグは件数、歌詞は紙の目印で表示。分類の目印を設定で変更できます。
- 一覧は100曲ずつ表示し、検索と絞り込みは全曲が対象です。アーティスト表示と長い曲名の横移動は設定で切り替えられます。画面外の曲名は動かしません。
- 歌う分類の追加、改名、並べ替え、削除時の曲の移動。
- ジャンル・思い出・アーティストの複数登録と入力候補。
- 知名度／流行度、西暦、キー変更、自由メモ。
- 地声最高音、裏声最高音、最低音、それぞれの音高・歌詞の一節・該当文字。
- 歌詞の改行表示、拡大表示、文字サイズ変更。対応端末では歌詞表示中の自動ロックを抑制。
- 複数語検索、分類・ジャンル・思い出・西暦・知名度・歌詞の有無での絞り込み、並べ替え。
- 1行1曲の一括追加（1回500曲まで）。タブ区切りのアーティスト列にも対応。
- ゴミ箱、復元、完全削除。
- JSONによる全楽曲・分類・表示設定・ゴミ箱の書き出しと復元。直前の復元の取り消し。
- CSV出力。歌詞の有無を選択可能。複数値は「 / 」区切り。
- 設定から背景色・アクセント色をRGB（0〜255）で変更、プレビュー、保存。冬のグレーと水色に戻せます。
- オフラインでの起動・登録・編集・検索。更新は通知から適用。

## 保存とバックアップ

通常データはブラウザのIndexedDBに保存されます。サーバーやアカウントへの保存・自動同期はありません。

- 同じURLでも、異なる端末・ブラウザには同じデータは現れません。
- サイトデータの削除・端末故障などに備え、JSONを定期的に書き出してiCloud Driveなどへ保存してください。
- 書き出し後は、ファイルが保存先にあることを確認してください。アプリが表示する日時は書き出し操作の日時です。
- JSONは復元用の完全なデータです。未登録の下書きは含みません。
- JSONからの復元は全体置き換えです。合流・自動同期は行いません。復元前の内容を端末内に1世代退避します。
- CSVは閲覧・加工用です。CSVからの読み込みはありません。
- 書き出したファイルは暗号化されていません。
- JSONの読み込み上限は25 MiB、ライブラリ上限はゴミ箱を含め10,000曲です。書き出し容量の上限ではありません。設定の「容量を確認」で実際のサイズを確認できます。詳しくは [性能と容量](PERFORMANCE.md) を参照してください。

## 安全性

- 外部ライブラリ・外部フォント・アクセス解析・データ送信APIを使用しません。
- 通信は同一サイトのアプリファイル取得・更新だけです。GitHub Pages自体のアクセス記録はGitHubの管理対象です。
- 入力文字列はHTMLとして解釈しないようエスケープし、Content Security Policyを設定しています。
- JSONは形式・件数・参照・文字数・RGB値などを検証し、未知のプロパティをコピーしません。
- CSVは、表計算で式として評価される文字列を無害化します。
- 別画面による更新を検出し、保存済みデータの無断上書きを防ぎます。
- 実際の歌詞・個人の楽曲データ・バックアップ・認証情報をこのリポジトリへ追加しないでください。

## ローカルで確認する

Node.js 20以上で、追加パッケージのインストールは不要です。

```sh
npm run dev
```

表示された `http://127.0.0.1:4173/OHAKO/` を開きます。このサーバーは開発中だけ必要です。公開後にPCを起動し続ける必要はありません。

```sh
npm test
```

JSON往復、異常なバックアップ、CSV、検索、一括追加、文字選択位置、RGB設定と旧データ互換を確認します。

## 公開・更新

GitHub Pagesの設定は「Deploy from a branch」「main」「/ (root)」です。ビルドは不要です。

アプリを更新する際は、`sw.js` の `CACHE` 名も更新してください。利用中の画面には更新通知を出し、入力中の下書きを保存してから切り替えます。データ保存先のURLのドメインを変える場合は、先にJSONを書き出し、新しい場所で復元してください。

## 確認してほしい端末操作

iPhone実機でのホーム画面への追加、共有メニューの「ファイルに保存」、文字入力と文字選択、機内モードでの起動は、実機で最終確認してください。開発時にはブラウザのiPhone相当幅で主要操作を確認しています。
